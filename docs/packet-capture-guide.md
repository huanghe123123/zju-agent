# 抓包指南

这份指南用于把当前 mock 数据层替换成真实的学在浙大、智云课堂和课程表接口。

## 准备

1. 使用 Chrome 或 Edge 打开目标网站。
2. 按 `F12` 打开 DevTools。
3. 进入 `Network` 面板，勾选 `Preserve log`。
4. 过滤器优先选 `Fetch/XHR`。
5. 登录后操作目标功能页面。

## 需要抓的接口

### 学在浙大 DDL

目标操作：

1. 进入学在浙大课程首页。
2. 打开作业、测验、讨论或待办列表。
3. 找到返回 DDL 列表的请求。

需要记录：

- Request URL
- Method
- Query string 或 Request payload
- Response JSON 示例
- 是否需要特殊 header

### 学在浙大课程文件

目标操作：

1. 打开某门课程。
2. 进入课件、资料、文件、章节内容页面。
3. 点击下载一个小文件。

需要记录：

- 文件列表接口
- 文件详情接口，如果存在
- 下载链接接口
- 下载是否依赖 cookie、token、一次性 URL

### 智云课堂

目标操作：

1. 进入智云课堂首页。
2. 打开课程列表。
3. 分别进入直播入口、回放页面、资料页面。

需要记录：

- 课程列表接口
- 直播入口接口或跳转 URL
- 回放列表接口
- 资料列表或下载接口

### 课程表和考试安排

第一版可以先从学在浙大课程列表做简化版。如果要接教务系统，需要抓：

- 当前学期课程表接口
- 考试安排接口
- 学年、学期参数来源

## 脱敏规则

提交给项目时请打码：

- Cookie
- Authorization
- ticket、token、code
- 学号、姓名、手机号
- 任何下载 URL 中的一次性签名

保留字段结构和值类型即可，例如：

```json
{
  "Authorization": "Bearer <masked>",
  "studentId": "<masked>",
  "courseId": "123456"
}
```
